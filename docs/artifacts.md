Перечень артефактов проекта:
| Артефакт | Где находится | В репозитории | Создаётся |
| :--- | :--- | :--- | :--- |
| Исходный код (*.cs, *.xaml) | папки проектов | да | разработчиком |
| Файлы проектов и решения (*.csproj, *.slnx / *.sln) | корень и папки проектов | да | Visual Studio |
| Настройки (appsettings.json) | ServiceDesk.Api | да, без секретов | разработчиком |
| Секреты (ключ JWT) | хранилище секретов пользователя | нет | разработчиком (работа 28) |
| Миграции БД | ServiceDesk.Data/Migrations | да | EF Core |
| Файл БД fooddelivery.db | ServiceDesk.Api | нет | при запуске API |
| Сборки bin/, obj/ | папки проектов | нет | при сборке |
| Журналы logs/ | рядом с API; %LOCALAPPDATA% для клиента | нет | при работе |
| Тесты | ServiceDesk.Tests, ServiceDesk.UiTests | да | разработчиком |
| Документация | docs/, README.md | да | разработчиком |
