# FoodDelivery — сервис доставки еды
Учебная практика УП.02, вариант N 4. Автор: <Байрамова Камилла>, группа <23ИСпк-9>.
## Технологии
C#, .NET 10, ASP.NET Core Web API, Entity Framework Core + SQLite, WPF, xUnit.
## Описание проекта
Система автоматизации процесса доставки еды.
Главные роли: Оператор (принимает заказы), Повар (готовит), Курьер (доставляет), Администратор (управляет системой).
Главная сущность: Заказ (Order), который проходит жизненный цикл от статуса «Новый» до «Доставлен» или «Отменён».
## Запуск
1. Открыть FoodDelivery.slnx (или ваш .sln) в Visual Studio.
2. Запустить проекты FoodDelivery.Api и FoodDelivery.Desktop (если WPF-приложение называется иначе, укажите ваше имя).

## Правила работы с ветками
В проекте используется упрощенный Git Flow.
- Ветка `main` — только стабильные релизы.
- Ветка `develop` — интеграционная ветка для разработки.
- Для каждой задачи создается ветка `feature/<номер>-<название>`.
- Слияние в develop происходит только через Pull Request.
